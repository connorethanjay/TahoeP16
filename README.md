# TahoeP16

TahoeP16 is an open-source repository hosting custom kernel extension (kext) source code, ACPI patches, and configuration files designed to bring macOS 27 Tahoe support to the Lenovo ThinkPad P16 Gen 3 mobile workstation.

The project focuses on reverse engineering and custom driver implementation for hardware components unsupported out-of-the-box by macOS.

AI-assisted code is present in this repository.
